# 🎨 Prompt Studio

Prompt Studio is a modern web application that allows users to generate AI-powered artwork through text prompts. Built with **React** and powered by **Hugging Face Inference APIs**, it bridges the gap between complex AI models and a user-friendly interface.

### ✨ Features
* **AI Generation:** High-fidelity image generation using Flux and SDXL models.
* **Style Selector:** Built-in prompt engineering for styles like Cyberpunk, Studio Ghibli, and Pixel Art.
* **Instant Download:** Save your generated masterpieces directly to your device.
* **Responsive UI:** A dark-themed, minimalist gallery experience.

### 🛠️ Tech Stack
* **Frontend:** React.js, Vite
* **Styling:** CSS3 (Custom Glassmorphism)
* **AI Engine:** Hugging Face Inference API
* **Environment:** Node.js

### 🚀 Setup Instructions
1. Clone the repository: `git clone https://github.com/YourUsername/prompt-studio.git`
2. Install dependencies: `npm install`
3. Create a `.env` file and add your token: `VITE_HF_TOKEN=your_token_here`
4. Start the development server: `npm run dev`
